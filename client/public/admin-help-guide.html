Bernardino Martin Website Admin Guide

Simple instructions for updating the website, reviews, images, and Google settings.

Login at: /admin/login
Tip: There are 2 admin areas. Use /admin for appointments and invoices. Use /admin/cms for website content, reviews, images, and SEO.

1. Sign In

  1. Open the admin login page.
  2. Enter the admin password.
  3. Click Sign In.
  4. Choose either the regular admin or the CMS control panel.

2. Business Info

Open Business Info to update:

  • Phone number
  • Email address
  • Business address
  • WhatsApp number
  • Facebook, Instagram, YouTube
  • Business tagline
  • Easter promotion details

3. Reviews

Use Reviews to manage customer feedback on the homepage.

  • Click Add New Review
  • Fill in the customer name, city, service, stars, and review text
  • Leave Show on Website turned on
  • Click Save Review

4. Media Library

Use Media Library to upload images for the website.

  • Click the upload box
  • Select a JPG, PNG, or WebP image
  • After upload, click Copy URL
  • Paste that image URL into a custom page or content area

5. SEO Settings

Use SEO Settings to control how pages appear in Google.

  • Update the page title
  • Update the Google search title
  • Update the Google description
  • Turn Google visibility on or off

6. Custom Pages

Create new pages for services and cities to help more customers find the business online.

  • Click Create New Page
  • Enter the page URL slug
  • Add the page title, heading, and content
  • Add a hero image URL
  • Turn on Published
  • Click Save Page

Quick Example

To create a page for AC repair in Burbank:

  1. Open Custom Pages
  2. Set the slug to ac-repair-burbank
  3. Write the title and page content
  4. Add an image from the Media Library
  5. Turn on Published
  6. Save the page

The page will then be available at: bernardinomartinhvac.com/ac-repair-burbank

If Something Does Not Show

  • Make sure you clicked Save
  • Check that the page is marked Published
  • Check that the review is marked Show on Website
  • Make sure the image uploaded correctly
  • Make sure the image URL is correct
